# ATT005 Filename contains a right-to-left override

## What it detects

The filename contains a Unicode direction override (U+202A–U+202E, U+2066–U+2069). `invoice\u202Egnp.exe` renders as `invoiceexe.png` while remaining an executable.

## Why it matters

The override is itself the finding. Sanitisation replaces it with a visible `<RLO>` token so the report cannot be used as a delivery mechanism.

## Example

See `corpus/malicious/homograph-attachment.eml`.

## Known false positives

Almost never legitimate. Direction overrides in filenames are a known malware trick.
