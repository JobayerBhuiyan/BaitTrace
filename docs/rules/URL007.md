# URL007 Redirect chain ends on an unrelated domain

## What it detects

`--follow-redirects` was passed, the client followed the URL (SSRF-hardened), and the terminal registrable domain differs from the original.

## Why it matters

The first hop is not the destination. Phishing kits wrap the payload in a redirector so scanners see a "clean" host.

## Example

```
http://go.mail-secure.example/r  ->  http://collect.example/login
```

Off by default: following a phishing link can confirm to the attacker that a live human received it.

## Known false positives

Marketing wrappers redirect through tracking domains. Confirm before treating as malice.
