# ATT002 Double extension disguises an executable

## What it detects

The filename ends in a document extension followed by an executable extension: `invoice.pdf.exe`.

## Why it matters

Windows hides known extensions by default, so the file shows as `invoice.pdf`. The last extension is the real one.

## Example

```
Content-Disposition: attachment; filename="invoice.pdf.exe"
```

## Known false positives

Almost never legitimate.
