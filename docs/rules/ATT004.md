# ATT004 Attachment is an executable, script, shortcut or disk image

## What it detects

The filename or sniffed type is an executable, script, shortcut (`.lnk`) or disk image (`.iso` / `.img`).

## Why it matters

These types execute code when opened. They have no business arriving unsolicited in email.

## Example

```
Content-Disposition: attachment; filename="setup.exe"
```

## Known false positives

Software vendors distributing installers. Confirm the sender independently.
