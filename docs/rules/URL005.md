# URL005 Link hides the real host behind userinfo

## What it detects

The URL uses the userinfo `@` trick so a brand name appears before the real host: `https://apple.com@evil.example/reset`.

## Why it matters

A browser contacts the host *after* `@`. The brand prefix is decoration. This is almost never legitimate in mail.

## Example

```
http://apple.com@evil.example/reset
```

## Known false positives

Almost never legitimate in mail. Credentials in URLs are a defect even when benign.
