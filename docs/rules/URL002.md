# URL002 Link host uses punycode or mixed scripts

## What it detects

A URL host is internationalised (`xn--`) or mixes writing systems within the name.

## Why it matters

Homograph attacks make one alphabet impersonate another in a link the same way they do in a From domain.

## Example

```
https://xn--pple-43d.example/recover
```

## Known false positives

Non-English organisations use internationalised domains legitimately.
