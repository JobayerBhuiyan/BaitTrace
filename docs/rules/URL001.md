# URL001 Link uses an IP address as the host

## What it detects

A URL's host is a raw IPv4 or IPv6 address rather than a domain name.

## Why it matters

Legitimate brands do not send customers to `http://198.51.100.23/account`. An IP host hides the organisation and is a staple of phishing kits.

## Example

```
Confirm here: http://198.51.100.23/account/verify?id=8831
```

## Known false positives

Internal monitoring systems sometimes link to literal IPs on a private LAN.
