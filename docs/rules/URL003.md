# URL003 Anchor text disagrees with the link target

## What it detects

Visible link text names one domain while the href points at another.

## Why it matters

Readers trust the painted URL. `https://www.paypal.com/invoice` wrapping `http://evil.example/pay` is the textbook bait.

## Example

```html
<a href="http://billing-paypa1.example/pay">https://www.paypal.com/invoice</a>
```

## Known false positives

URL shorteners and tracking wrappers often display a clean name over a redirector.
