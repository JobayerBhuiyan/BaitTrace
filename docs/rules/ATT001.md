# ATT001 Declared MIME type does not match file contents

## What it detects

The Content-Type header disagrees with the file's magic bytes.

## Why it matters

The declared type is attacker-controlled. A `.pdf` that sniffs as `application/x-dosexec` is an executable.

## Example

A part declared `application/pdf` whose payload starts with `MZ`.

## Known false positives

Some mail clients declare `application/octet-stream` for everything; that value is ignored.
