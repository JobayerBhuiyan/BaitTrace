# URL004 Link uses a known URL shortener

## What it detects

The host is in the vendored shortener list (`src/baittrace/data/shorteners.txt`).

## Why it matters

A shortener hides the real destination. Following it can also beacon.

## Example

```
http://bit.ly/abc123
```

## Known false positives

Legitimate marketing mail uses shorteners. Weighted medium for this reason.
