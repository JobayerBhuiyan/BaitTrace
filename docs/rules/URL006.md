# URL006 Link puts a brand name on an unrelated domain

## What it detects

A brand alias appears in a URL label or path on a domain that is not in that brand's authorised list. Same confusable-skeleton matching as IDN003.

## Why it matters

`http://microsoft-login.thief.example/secure` looks like Microsoft to a glancing reader. The registrable domain is `thief.example`.

## Example

```
http://microsoft-login.thief.example/secure
```

## Known false positives

Resellers and status pages sometimes put a brand in a path they do not own.
